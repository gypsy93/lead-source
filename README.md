# lead-source

**어디서 온 리드인지 남기고, 그 숫자로 어디서 끊겼는지 짚어주는 Claude Code 스킬.**

## 이 중에 하나라도 겪었다면 이 스킬입니다

- 카톡에 링크를 보냈는데 **미리보기 카드가 안 뜬다**
- **아무도 안 눌렀는데 클릭 수가 올라** 있다
- 링크를 눌러서 들어갔는데 유입이 **「직접 방문」으로 뜬다**
- 미리보기 그림을 고쳤는데 **카톡에서는 옛것이 계속 뜬다**
- 시험 데이터를 지웠더니 **「지난주까지 몇 명이었나」를 못 세겠다**
- **클릭은 20인데 신청이 0이다.** 채널 문제인가 첫 화면 문제인가

마지막 줄이 이 스킬의 이유입니다. **그 둘은 고칠 곳이 완전히 다른데, 숫자만 봐서는 안 갈립니다.**

## 무엇을 하나

1차 전환(무료로 뭔가 주고 연락처를 받는 단계)에서 **내보낸 링크와 들어온 사람을 잇습니다.**

- 채널별 UTM + 짧은 링크 세트 — 한 번 나가면 못 고치는 태그 이름 규칙부터
- 폼·랜딩에 유입 경로가 자동으로 남게 붙이는 법
- 링크별 **클릭 → 신청 → 전환율** 성적표
- 그 숫자로 **어디서 끊겼는지** 나누는 판단표

```
클릭 0                  →  채널이 틀렸거나 콘텐츠가 안 끌렸다
클릭은 있는데 신청 0     →  첫 화면이 문제다
끝까지 갔는데 미제출      →  폼이나 혜택이 문제다
```

## 다른 UTM 안내문과 뭐가 다른가

**「숫자가 거짓말하는 자리」를 막아준다는 점**입니다. 넷 다 직접 부딪혀서 알아낸 것이고, **넷 다 내보낸 뒤에는 되돌릴 수 없습니다.**

| | 무슨 일이 일어나나 |
|---|---|
| **미리보기 봇** | 카톡·링크드인에 링크를 붙이면 그 회사 서버가 링크를 연다. 20명에게 보내면 **아무도 안 눌러도 클릭 20** |
| **넘김을 안 따라감** | 카카오는 리다이렉트를 따라가지 않아, 짧은 링크에 카드가 안 뜬다 |
| **지운 행** | 시험 데이터를 지우면 **그 사람이 있었다는 사실까지** 사라진다 |
| **확인하는 사람** | 코드는 다 멀쩡한데 **옛 탭에서 완주해서** 유입이 안 붙는다 |

첫 번째가 특히 위험합니다. **「클릭 20 · 신청 0」이 「눌렀는데 아무도 안 남겼다」로 읽히는데, 실제로는 한 명도 안 누른 것**입니다. 그러면 첫 화면을 고치느라 채널을 안 바꾸게 됩니다.

## 코드를 안 써도 됩니다

두 갈래로 나눠 뒀습니다.

- **`references/no-code.md`** — 단축링크 서비스 + 구글폼 사전 채움 + 스프레드시트 성적표. 구글폼에 숨김 항목이 없는 문제를 정공법으로 푸는 법까지
- **`references/with-code.md`** — 직접 만든 사이트에 붙이기. 링크 표 · 짧은 링크 경로(사람/봇 분기) · 클릭 세기 · 봇 판별 · 미리보기 카드 · 누적 카운터

## 설치

**모든 프로젝트에서 쓰려면** — 한 줄이면 됩니다.

```bash
git clone --depth 1 https://github.com/gypsy93/lead-source.git ~/.claude/skills/lead-source
```

**한 프로젝트에서만 쓰려면** 뒤의 경로를 `.claude/skills/lead-source` 로 바꿉니다.

제대로 들어갔는지 확인 — **파일 넷**이 나오면 됩니다.

```bash
find ~/.claude/skills/lead-source -name "*.md"
```

```
SKILL.md
README.md
references/no-code.md
references/with-code.md
```

🔴 **`references/` 를 빼고 `SKILL.md` 만 가져가지 마세요.** 본문은 「무엇을 왜」까지만 담고, **실제로 붙이는 방법은 참고 파일 둘에 있습니다.** 없으면 스킬이 「그건 참고 파일에 있습니다」라고만 하고 멈춥니다.

설치 후 **다음 세션부터** 잡힙니다. 열려 있는 클로드 코드는 한 번 재시작하세요.

## 쓰는 법

**말로 부르지 않아도 걸립니다.** 채널을 두 개 이상 돌리려는 맥락이거나, 위 증상 중 하나를 말하면 자동으로 발동합니다.

```
링크 돌릴 건데 유입 추적 붙여줘. 채널은 카톡, 링크드인, 스레드.
```

이렇게 불러도 되고요.

## 범위 밖

광고 성과 분석과 멀티터치 기여도 배분(여러 번 접촉한 사람의 공을 채널마다 나누는 것)은 다루지 않습니다. **한 사람이 마지막에 어느 링크로 들어왔는지**까지만 봅니다.

## 옆에 서는 스킬

이 스킬은 **「내보낸 뒤」만** 맡습니다.

```
lead-offer-design   무엇을 줄지 · 왜 아무나 안 주는지
lead-form           신청을 받아 담을 그릇
privacy-build       동의 문구 · 처리방침
lead-source         ← 내보낸 뒤, 어디서 왔는지 세고 읽기
```

앞의 셋이 서 있지 않으면 여기부터 하지 않습니다. 셀 것이 없습니다.
